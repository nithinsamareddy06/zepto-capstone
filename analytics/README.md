# Analytics Pipeline — Module 2

See the root `README.md` for full setup/run instructions and design decisions.

Quick run:
```bash
pip install -r requirements.txt
python3 01_eda.py
python3 02_modeling.py
```

All required written interpretations (missing-value justifications, outlier
counts, skewness discussion, correlation interpretation, the 4 data-story
chart write-ups, the imbalance-handling conclusion, the heteroscedasticity
conclusion, and the final model recommendation) are generated into
`eda_report.md` and `model_report.md` by the scripts above.
